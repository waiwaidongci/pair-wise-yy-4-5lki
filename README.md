# 水下考古样本移交台

直接打开 `index.html` 使用，数据保存在浏览器 localStorage。

## 规则

- 样本以「潜次 + 编号」唯一，重复登记会被拒绝。
- 流转严格依次为：**出水登记 → 封存复核 → 入库移交**，不能跳步（按钮只在合法阶段出现，接口层同样拦截）。
- 封存复核时若修改**深度 / 朝向 / 保存状态**，旧值保留为历史版本，并生成一条**待确认修订**；确认通过才产生新版本，驳回则维持原值。
- 同一记录同时只能有一条待确认修订；重复确认**沿用首次结果**，不会再次改值。
- 入库后再修订：原入库移交立即**失效**，样本**退回待复核**；旧版本仍可查，且始终归属原潜次，不会混入其他潜次清单/时间线。
- 潜水员与复核人（及再修订申请人、修订确认人）不得相同。
- 类型/潜次筛选、清单/时间线视图、选中记录随 localStorage 持久化，刷新后一致；导出 JSON 按当前筛选输出，含完整版本与流转历史。

## 操作

1. 点击沉船平面图选取出水点位，在右侧完成出水登记。
2. 在样本详情中由非潜水员完成封存复核（可附修订）。
3. 待确认修订由确认人通过/驳回，随后办理入库移交。
4. 已入库样本可申请再修订，移交将失效并退回待复核。
