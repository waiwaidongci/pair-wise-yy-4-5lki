# 水下考古样本移交台

直接打开 `index.html` 使用，数据保存在浏览器 localStorage，无需后端。

## 移交流程（不可跳步）

样本以 **潜次 + 编号** 唯一标识，依次经过：

1. **出水登记**（registered → 待封存复核）
2. **封存复核**（reviewed → 待入库移交）
3. **入库移交**（stored → 已入库）

复核时修改深度、朝向或保存状态会保留旧版并生成「待复核修订」，确认后才生效；未修改则直接通过。

## 修订规则

- 同一记录同时只允许一条待确认修订；已有待确认修订时不能再发起。
- 修订确认/驳回是幂等的：重复操作一律沿用首次结果（首次决定人与时间不可覆盖）。
- **入库后再修订**：原入库移交立即失效（库位、接收人、时间清空），记录回到待复核；旧版数据与原入库信息仍保留在版本记录和流转时间线中，确认或驳回后需重新办理入库移交。
- 修订记录始终绑定原样本与原潜次，不会出现在其他潜次清单中。
- **潜水员与复核人不得为同一人**，提交时强制校验。

## 筛选、时间线与导出

- 类型 / 状态（含「待确认修订」「入库失效回落」）/ 潜次 / 关键字筛选。
- 地图标记、样本清单、潜次时间线、JSON 导出共用同一筛选结果，刷新页面后筛选条件、视图与选中样本保持一致。
- 「查看全部版本与记录」可追溯 v0 登记版与每条修订（待确认/已确认/已驳回）及完整流转事件。
